# Reisegruppe Ushaq al-Hussein

أنشئ تطبيق ويب حديث وأنيق ثنائي اللغة (عربي وألماني فقط حصراً) لحملة:

"حملة عشاق الحسين - ألمانيا | Reisegruppe Ushaq al-Hussein"



شرط أساسي: جميع النصوص والواجهات والعناوين يجب أن تكون بلغة عربية وتحتها مباشرة الترجمة الألمانية (AR / DE)، ويمنع استخدام اللغة الإنجليزية نهائياً في التطبيق.



الهوية والتصميم:

- الألوان: أزرق كحلي داكن (#0D1B2A) كـ لون رئيسي، مع لمسات ذهبية (#D4AF37)، وخلفية فاتحة مريحة للعين.

- التصميم: مخصص للعرض على الهواتف المحمولة (Mobile-first).



أقسام الصفحة:

1. الترويسة (Header):

   - العنوان: حملة عشاق الحسين - ألمانيا | Reisegruppe Ushaq al-Hussein

   - تحت العنوان: بإدارة الحاج ياسر الدر | Geleitet von Hajj Yasser Aldor



2. الرحلات المتاحة (Verfügbare Reisen):

   - عرض الرحلات بطاقات أنيقة (زيارة العراق، العمرة، إيران، الحج) مع التواريخ والتفاصيل.



3. قسم التسجيل (Anmeldeformular):

   - مساحة مخصصة لعرض استمارة التسجيل (Google Form) وزر مباشر للتسجيل.



4. أرقام التواصل (Kontaktnummern):

   - أزرار تواصل مباشرة مع المسؤولين (الحاج ياسر الدر، الحجة سامية فقيه، الحجة خديجة إسماعيل).



5. قسم آخر الأخبار (Neuigkeiten) والمساهمات (Spenden).
